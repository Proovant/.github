# Proovant
### Find it. Challenge it. Prove it.

Proovant is an AI-assisted smart contract security review engine designed to identify vulnerabilities, challenge potential findings, and validate them with executable proof-of-concept tests.

We combine specialised AI analysis with adversarial validation and Foundry-based testing to make security findings more reproducible and actionable.

**[Website](https://www.proovant.com)** · **[X](https://x.com/Proovant_ai)**

---

## How It Works

**01 — Scope & Threat Model**  
Map the codebase, identify critical contracts and value flows, and establish the threat model.

**02 — Parallel Security Analysis**  
Specialised agents analyse different vulnerability classes, including accounting, access control, state transitions, external calls, and economic logic.

**03 — Adversarial Validation**  
A separate review stage challenges candidate findings, testing reachability, impact, and whether the issue is already addressed.

**04 — Executable Proof of Concept**  
Surviving candidates are developed into Foundry tests to demonstrate the described behaviour under documented assumptions.

**05 — Report & Review**  
Findings are documented with severity reasoning, impact, reproduction steps, and remediation guidance.

## Our Approach

- Evidence over speculation
- Adversarial validation before reporting
- Reproducible PoCs
- Clear impact and remediation guidance
- Transparent scope and limitations

Proovant is AI-assisted security analysis. It does not guarantee that a codebase is vulnerability-free and does not replace a comprehensive independent security audit.
